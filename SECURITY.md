# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository, please report it privately by email:

**ryanjede@gmail.com**

Please do **not** open a public GitHub issue for suspected security vulnerabilities.

Include:
- a clear description of the issue
- steps to reproduce it, if available
- affected file(s) or function(s)
- any proof-of-concept or relevant output

## Scope

This policy is intended for genuine security issues, such as:
- arbitrary code execution risks
- unsafe file handling
- dependency-related security concerns

It is **not** intended for:
- numerical disagreements
- scientific disputes
- feature requests
- general bug reports that are not security-relevant

## Response

Reports will be reviewed on a best-effort basis. If the issue is confirmed, a fix may be made privately before public disclosure.
