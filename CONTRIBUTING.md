# Contributing

Thanks for your interest.

This repository is primarily maintained as a research/reference codebase.

At present, unsolicited code contributions and pull requests are not being accepted unless explicitly invited.

Helpful reports may include:
- reproducibility problems
- clear bugs
- environment/setup issues
- documentation errors

Please use private email for security-related issues:
**ryanjede@gmail.com**

Please do not use GitHub issues for:
- general scientific disputes
- licensing requests
- commercial use requests
- security vulnerabilities
